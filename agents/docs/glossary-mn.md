# BuildWatch — Нэр томьёоны тайлбар (NFR-09)

Системд хэрэглэгддэг нэр томьёог монгол-англи хосоор тайлбарлав. UI, баримт бичиг, агентын
гаралт бүгд эдгээр нэрийг тогтвортой хэрэглэнэ.

## Төлөвлөлт ба хуваарь

| Монгол               | Англи                          | Тайлбар                                                                                                               |
| -------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| Суурь төлөвлөгөө     | Baseline                       | Батлагдсаны дараа өөрчлөгдөхгүй, харьцуулалтын жишиг болох төлөвлөгөө. Шинэ хувилбар гаргаж л өөрчилнө                |
| Ажлын задаргаа       | WBS (Work Breakdown Structure) | Төслийг удирдаж болохуйц жижиг ажлууд болгон мод хэлбэрээр задалсан бүтэц                                             |
| Ажлын мөр            | Work item                      | Задаргааны хамгийн доод түвшний, гүйцэтгэл хэмжигддэг нэгж ажил                                                       |
| Хамаарал             | Dependency                     | Хоёр ажлын дараалал: FS (дуусаад эхлэх), SS (хамт эхлэх), FF (хамт дуусах), SF (эхлээд дуусах)                        |
| Эгзэгтэй зам         | Critical path                  | Нийт хугацааг тодорхойлдог ажлуудын гинж. Энэ дээрх аль нэг ажил хоцровол төсөл шууд хоцорно                          |
| Нөөц хугацаа         | Float / slack                  | Тухайн ажил төслийн дуусах хугацаанд нөлөөлөхгүйгээр хэдэн хоног хоцорч болох нь. Эгзэгтэй зам дээрх ажлын float нь 0 |
| CPM                  | Critical Path Method           | Хамаарал болон ажлын календарийг ашиглан эгзэгтэй зам, float-ыг детерминистикээр тооцох арга                          |
| Ажлын календарь      | Working calendar               | Ажлын өдөр, амралт, баярыг тодорхойлох хуваарь. Бүх хугацааны тооцоо үүнийг баримтална                                |
| Прогноз дуусах огноо | Projected finish               | Бодит явцын хурдад тулгуурлан тооцоолсон дуусах огноо (төлөвлөсөн огноотой ижил биш)                                  |

## Тоо хэмжээ ба төсөв

| Монгол                 | Англи                    | Тайлбар                                                                                |
| ---------------------- | ------------------------ | -------------------------------------------------------------------------------------- |
| Тоо хэмжээний түүвэр   | Quantity takeoff         | Зураг төслөөс материал/ажлын тоо хэмжээг гаргаж авах үйл явц                           |
| Тоо хэмжээний жагсаалт | BOQ (Bill of Quantities) | Ажил тус бүрийн тоо хэмжээ, нэгж үнэ, дүнг жагсаасан баримт                            |
| Төсөв                  | Estimate                 | Тоо хэмжээ × нэгж үнэ дээр норм, хаягдал, НӨАТ, нөөц зардлыг нэмж тооцсон мөнгөн дүн   |
| Норм                   | Norm                     | Нэгж ажилд ногдох материал/хөдөлмөрийн стандарт хэмжээ                                 |
| Хаягдлын хувь          | Waste factor             | Практикт үүсэх хаягдлыг нөхөх нэмэлт хувь                                              |
| Нөөц зардал            | Contingency              | Урьдчилан тооцоогүй зардлыг нөхөх нөөц хувь                                            |
| Дэвтэр бүртгэл         | Ledger                   | Мөнгөн гүйлгээний нарийвчилсан бүртгэл. Бүх тооцоо бутархайн алдаагүй, яг таг хийгдэнэ |

## Гүйцэтгэл ба хяналт

| Монгол                       | Англи                 | Тайлбар                                                                                        |
| ---------------------------- | --------------------- | ---------------------------------------------------------------------------------------------- |
| Өдрийн тайлан                | Daily report          | Талбайгаас ирэх өдөр тутмын гүйцэтгэл, ирц, материал, саадын бүртгэл                           |
| Гүйцэтгэлийн баталгаажуулалт | Progress verification | Мэдүүлсэн явцыг фото нотолгоо, хэмжилт, чеклистээр шалгаж баталгаажуулах                       |
| Хазайлт                      | Deviation             | Төлөвлөгөө ба бодит гүйцэтгэлийн хоорондох зөрүү                                               |
| Үндсэн шалтгаан              | Root cause            | Хазайлтыг үүсгэсэн жинхэнэ эх шалтгаан (шинж тэмдэг биш)                                       |
| S-муруй                      | S-curve               | Хугацааны туршид хуримтлагдсан гүйцэтгэлийг харуулах график. Төлөвлөгөө ба бодитыг зэрэгцүүлнэ |
| Анхааруулга                  | Alert                 | Дүрэм эсвэл баталгаажуулалтаас автоматаар үүссэн, хүний анхаарал шаардах дохио                 |
| Сэргээх хувилбар             | Recovery scenario     | Хоцролтыг нөхөх боломжит арга ба түүний хуваарь/зардалд үзүүлэх тооцоолсон нөлөө               |

## Систем ба архитектур

| Монгол                   | Англи                            | Тайлбар                                                                                               |
| ------------------------ | -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Түрээслэгч               | Tenant                           | Системийг ашиглаж буй нэг компани. Компаниудын өгөгдөл хооронд огт харагдахгүй                        |
| Түрээслэгчийн богино нэр | Tenant slug                      | Нэвтрэхэд ашиглагдах компанийн богино тэмдэглэгээ (жишээ нь `nomad-build`). Дотоод `tenantId`-аас өөр |
| Эрхийн хяналт            | RBAC (Role-Based Access Control) | Хэрэглэгчийн үүрэгт тулгуурлан юу үзэх/хийхийг зөвшөөрөх систем. 7 үүрэгтэй                           |
| Батлагдсан команд        | Approved command                 | Хүн баталсны дараа л system-of-record өөрчилдөг цорын ганц бичих зам                                  |
| Гаралтын хайрцаг         | Outbox                           | Өгөгдөл өөрчлөх гүйлгээтэй нэг зэрэг үйл явдал бичиж, дараа нь найдвартай хүргэх загвар               |
| Давтагдашгүй байдал      | Idempotency                      | Нэг үйлдлийг олон удаа давтан илгээсэн ч үр дүн нэг л удаа үүсэхийг баталгаажуулах                    |
| Аудитын бүртгэл          | Audit log                        | Хэн, хэзээ, юуг өөрчилснийг бүртгэсэн, устгах/засах боломжгүй түүх                                    |
| Гарын үсэгтэй холбоос    | Signed URL                       | Богино хугацаанд хүчинтэй, эрх шалгасан файл татах түр холбоос                                        |
| Артефакт                 | Artifact                         | Систем үүсгэсэн эсвэл хэрэглэгч оруулсан файл (PDF, зураг, Excel)                                     |

## Агент ба AI

| Монгол                 | Англи                  | Тайлбар                                                                                    |
| ---------------------- | ---------------------- | ------------------------------------------------------------------------------------------ |
| Детерминистик          | Deterministic          | Ижил оролтод үргэлж яг ижил үр дүн өгөх тооцоолол. Бүх тоон утга ийм замаар гарна          |
| Эх сурвалжийн лавлагаа | Source reference       | Гаргасан утга бүр ямар өгөгдлөөс гарснаа заасан заалт. Ул мөрийг бүрэн сэргээх боломжтой   |
| Итгэлцлийн оноо        | Confidence score       | Агент тухайн талбарыг хэр итгэлтэй гаргасныг илэрхийлэх 0–1 хоорондох утга                 |
| Нотолгоо               | Evidence               | Гаргасан утгыг баталж буй эх бичвэрийн хэсэг эсвэл зургийн муж                             |
| Тодруулах асуулт       | Clarification question | Мэдээлэл дутуу эсвэл ойлгомжгүй үед агент хүнээс асуух асуулт                              |
| Ноорог                 | Draft                  | Агент бэлдсэн, хүн батлах хүртэл хүчин төгөлдөр бус санал                                  |
| Хиймэл зохиомол        | Hallucination          | LLM өгөгдөлд байхгүй зүйлийг зохиож гаргах алдаа. Тоог тооцооллоос авдаг бүтцээр сэргийлнэ |
| Шийдвэрийн хүснэгт     | Decision table (JDM)   | Дүрмийн босгыг кодгүйгээр засах боломжтой хүснэгт хэлбэрийн дүрмийн загвар                 |
| Автономи хаалт         | Autonomy gate          | Агент өөрөө шийдвэр гаргаж эхлэхийн өмнө давах ёстой тоон босго. Анхдагчаар унтраалттай    |

## Ажиллагаа

| Монгол                  | Англи                    | Тайлбар                                                                  |
| ----------------------- | ------------------------ | ------------------------------------------------------------------------ |
| Хүлээлгийн жагсаалт     | Queue                    | Дараалалд орсон, worker-ээр боловсруулагдах ажлууд                       |
| Үхсэн захидлын жагсаалт | Dead-letter queue        | Дахин оролдоод амжилтгүй болсон ажлууд очих тусгай дараалал              |
| Таслуур                 | Circuit breaker          | Гадаад үйлчилгээ тасралтгүй алдаа өгвөл дуудлагыг түр зогсоох хамгаалалт |
| Дахин тоглуулах         | Replay                   | Хадгалсан үйл явдлаас боловсруулалтыг дахин гүйцэтгэх                    |
| Бэлэн байдлын шалгалт   | Readiness / health check | Үйлчилгээ хүсэлт хүлээж авахад бэлэн эсэхийг шалгах endpoint             |
| Ажиглалт                | Observability            | Лог, метрик, trace-ээр системийн дотоод байдлыг харах чадвар             |
