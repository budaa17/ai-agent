# BuildWatch v2.0 шаардлага–хэрэгжүүлэлтийн матриц

Энэ матриц requirement, owner, хэрэгжүүлэх phase, бодит code/test evidence-ийг холбоно.

Төлөв:

- `DONE` — тухайн phase-ийн gate, code, test бүрэн;
- `PARTIAL` — ашиглаж болох хэсэг байгаа ч production gate дутуу;
- `NOT_STARTED` — хэрэгжүүлээгүй;
- `DEFERRED` — MVP-ийн дараа зориуд хойшлуулсан;
- `OUT_OF_SCOPE` — батлагдсан scope-д орохгүй.

## Gate дүрэм

- `DONE` мөрийг typecheck болон тухайн requirement-ийн deterministic test амжилттай үед л тэмдэглэнэ.
- Live OpenAI evaluation нь quota/зардал/model variability-тай тул optional; offline schema/rule/security gate заавал байна.
- Frontend/backend shared `v1` contract-ийг хэрэглэж, эвдэх өөрчлөлтийг шинэ schema version-оор гаргана.
- Production data-д model шууд write хийхгүй; хүний баталсан idempotent command л write boundary давна.
